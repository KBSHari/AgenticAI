## Known Dependencies / Open Items

- **Acceptance criteria coverage:** AC-001 to AC-006 and AC-008 to AC-010 each have at least one passing automated test. **AC-007 (README instructions) has no automated test**; this was found in the Phase 7 review and corrects an earlier statement in this manifest that all ten were automated. The README commands (`npm install`, `npx playwright install chromium`, `npm test`) were run during implementation, but the clean-checkout walkthrough (TC-019), the unsupported-Node-version check (TC-020), the port-in-use check (TC-021) and the failing-assertion mutation check (TC-017) from the QA plan remain manual and were not run. The design's coverage target ("every acceptance criterion mapped to an automated test") is therefore not fully met.
- **Coverage target not measured:** the 80 percent line-coverage target for `server/server.js` could not be measured, because a coverage provider package (for example `@vitest/coverage-v8`) is not among the approved dependencies and would need an ADR. The server tests exercise every route, status code and header branch except the generic 500 path, which cannot be triggered portably.
- **AC-009 is a localhost lower bound (flag F-2):** weight (under 100 KB, HTML and CSS only) and throttled LCP (under 2.5 s with 4x CPU and slow-4G emulation) pass on localhost; this does not model a real network.
- **Chromium only (flag F-3):** Firefox, Safari and Edge are a manual smoke check, noted in the README.
- **Anchor styled as a button (flag F-1):** tests query the link role.
- **Git root and remote (flag F-4):** the git root is the home directory and no remote is configured. Where `welcome-app/` is committed, and the target of the PR (for example `KBSHari/AgenticAI`), must be settled before Phase 10.
- **Generated output:** `node_modules/`, `test-results/` and `playwright-report/` exist locally and are ignored by `welcome-app/.gitignore`; `package-lock.json` is intentionally not ignored.
